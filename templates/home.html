Shopping Mode Prediction

Open predictor

Project overview

Predict how a customer prefers to shop.

This application uses customer profile, spending, payment, satisfaction, and influence data to predict whether a customer prefers online shopping, offline shopping, or either shopping mode.

Problem type

Multiclass classification

Three target categories:

  • Online
  • Offline
  • Equal / both

Model inputs

27 customer attributes

Profile, behavioral, financial, and satisfaction variables are collected before prediction.

Workflow

End-to-end prediction

  1. Collect customer responses
  2. Apply trained preprocessing
  3. Run the selected model
  4. Display the predicted mode and probabilities

Project objective

Turn customer behavior patterns into an understandable shopping preference prediction.
